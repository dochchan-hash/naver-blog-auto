# naver blog auto

레몬하우스 블로그 스튜디오 · Mac / Windows

시공 현장의 사진과 공사내용을 바탕으로 블로그 추천글·시공사례와 카페 마감글·공사전·공사중 글을 작성하는 개인용 프로그램입니다. 한 프로그램에서 글 종류를 선택하며 보관함과 작성 스타일을 따로 관리합니다. 각 직원의 컴퓨터에 사진·원고·계정 연결을 따로 보관합니다.

현재 소스의 핵심 기능과 검증·배포 상태는 [이어가기 핵심](CURRENT_STATUS.md)에 정리했습니다. 다섯 콘텐츠를 main에서 관리하며, 공사전·공사중은 기존 웹 프로그램의 작성 기능과 별도 양식을 유지합니다. 마감의 PSD 편집·사진 배치·지도·영상·태그 기능은 [카페 마감 안내](CAFE_COMPLETION.md)를 참고하세요.

2026-11-13 버전은 동영상 업로드 완료 대기·게시글과 영상 태그 입력·카페 임시저장, 템플릿 편집 자동 저장, 표지 사진 실시간 위치 조절, 공간별 사진 자동 묶음과 최대 10장 업로드 분할을 포함합니다. 거실·주방·안방의 부속 공간을 해당 공간 뒤에 두고 공용욕실은 마지막에 작성합니다. 콘텐츠별 작성 스타일은 분리하며, 시공사례에서 설명 없는 공간도 사진만 입력할 수 있습니다. 전체 자동 검사 296개와 화면 빌드를 통과했습니다.

## 실행

**[Windows 최신 실행본](https://github.com/dochchan-hash/naver-blog-auto/releases/latest)의 ZIP을 새 폴더에 모두 추출한 뒤 `레몬하우스 실행.cmd`를 실행하세요.** 현재 PC와 같은 추천글·시공사례·카페 마감 기능, 작성 스타일 3종, PSD 템플릿 7개가 포함됩니다. 계정·기존 원고·현장 사진은 포함하지 않으므로 ChatGPT와 네이버에는 직접 로그인합니다. Node.js 설치나 빌드는 필요하지 않습니다. 자세한 절차는 [Windows 사용 안내](WINDOWS_START.md)를 참고하세요.

GitHub의 **Code → Download ZIP**과 **Source code**는 개발용 소스입니다. 실행본은 **Releases**에서 받습니다. 이 저장소에는 개인 계정 연결, 현장 사진, 작성한 원고를 포함하지 않습니다. 새 컴퓨터에서는 ChatGPT와 네이버에 처음 한 번씩 로그인하세요.

직접 빌드한 작업 폴더에서는 Mac의 **레몬하우스 실행.command** 또는 Windows의 **레몬하우스 실행.cmd**를 사용하면 해당 폴더에 저장된 자료를 이어서 사용합니다. `release` 폴더가 필요합니다.

이 PC의 기존 **블로그 스튜디오 실행.cmd**는 이 폴더의 **레몬하우스 실행.cmd**를 거쳐 `release/win-unpacked`의 실행본을 엽니다. 추천글·시공사례·카페 마감·공사전·공사중을 모두 포함합니다. Windows 배포 ZIP도 같은 폴더 구조와 실행 스크립트를 사용하며, `.local`에는 기본 PSD·스타일과 사용 중 저장한 원고·사진·계정을 보관합니다. 기존 사용 폴더에 ZIP을 덮어쓰지 마세요. 소스·의존성·검사 파일은 개발 저장소에만 보관하며 배포 ZIP에는 넣지 않습니다.

- Mac Apple Silicon: `release/Lemonhouse Blog Studio-0.1.0-arm64.dmg`
- Mac Intel: `release/Lemonhouse Blog Studio-0.1.0.dmg`
- Windows 64비트: `release/Lemonhouse Blog Studio-0.1.0-win.zip`을 전부 풀고 `Lemonhouse Blog Studio.exe`를 실행합니다. 실행 파일만 따로 옮기지 마세요.

2026-10-08 업데이트는 Windows 실행본으로 제공합니다. 이전 Mac 실행본은 [v0.1.0 배포](https://github.com/dochchan-hash/naver-blog-auto/releases/tag/v0.1.0)에 남아 있습니다. Windows 앱의 실행과 네이버 편집기 입력을 확인했으며, 이번 업데이트의 Mac 실행본은 새로 만들지 않았습니다. 현재 배포 파일은 운영체제의 배포 인증을 받지 않은 개발용입니다.

이번 업데이트에는 사진의 8개 공간 자동 분류, 보관함 제목 수정·삭제, 작성 중단, 참고 링크 변경 시 본문·서식 재분석, 질문·답변 인용구 위치·개수 설정을 포함합니다. 공간 설명 누락·반복 말투와 문장 중간 줄바꿈을 검사하며, 네이버 편집기에서 인용구·사진·설명 순서와 서식, 표지의 네이티브 1:1 편집, 추천 인테리어 카테고리·태그·예약 시각을 확인합니다. 검증 범위는 [구현 및 검증 상태](WORK_STATUS.md)를 참고하세요.

## 처음 연결하기

1. **계정과 작성 스타일 → 계정 연결**에서 **Continue with ChatGPT**를 누르고 본인 계정으로 로그인합니다.
2. 담당 **블로그 아이디**를 입력하고 **네이버 계정 연결**을 누릅니다.
3. 프로그램이 연 네이버 창에서 직접 로그인합니다. 로그인 정보는 컴퓨터의 보안 저장소를 이용해 암호화하여 보관합니다.
4. **연결 확인**에서 담당 블로그를 확인합니다. 연결을 저장한 뒤에는 네이버 창을 닫아도 다음 작업에서 자동으로 불러옵니다.

네이버 로그인 상태가 만료되거나 서비스에서 재인증을 요구하면 다시 로그인해야 합니다. 다른 계정으로 작성하려면 **계정 변경**을 누르고 새 계정으로 로그인한 뒤 담당 블로그 아이디를 다시 입력하세요. 계정을 바꿔도 원고와 사진은 남습니다.

ChatGPT 연결은 공식 로그인으로 해당 계정에서 허용하는 모델과 사용량을 확인합니다. 유료 API로 자동 전환하지 않습니다. 무료 계정 및 개별 모델의 사용 가능 여부는 실제 계정 응답에 따릅니다.

## 추천글 작성

1. **현장 정보·도면**: 원본 시공 현장과 추천 대상 현장의 아파트명·지역을 입력하면 네이버 부동산에서 조회합니다. 여러 단지가 나오거나 지역이 다르면 주소를 확인해 선택합니다. 실제 평형·타입을 선택하면 공급·전용면적, 해당 도면, 네이버 단지 정보가 표시됩니다. 도면 비교도 같은 화면에서 선택적으로 진행합니다. 조회한 정보와 선택한 타입은 다시 실행해도 남습니다.
2. 첫 화면의 **공사내용**에서 공사범위 PDF·JPG를 끌어 놓고 카페 마감글을 불러옵니다. 두 자료에서 자재·규격·색상·공사 범위가 명확히 다르면 양쪽 근거와 차이를 표시합니다. 항목별로 파일 기준, 마감글 기준, 출처별 차이를 구분해 작성, 제외, 직접 수정 중 선택합니다. 선택 전 항목은 초안에서 보류하고 자동 발행을 멈춥니다. 자료에 없는 설명이나 더 자세한 설명을 자동으로 충돌로 취급하지 않습니다.
3. **사진 첨부·배치**: 여러 현장 사진을 끌어 놓습니다. 같은 공간의 사진 중앙이나 기존 묶음 안에 놓으면 함께 묶이고, 좌우 가장자리에 놓으면 순서를 조정합니다. 아래 단독 배치 영역으로 꺼내면 묶음에서 빠집니다. 사진 선택 버튼으로 묶기·해제도 가능합니다. 공사범위 자료는 게시 사진으로 포함하지 않습니다.
4. **원고 작성 → 발행**: 공사범위 파일, 카페 마감글, 현장 사진을 함께 확인해 추천글을 생성합니다. 선택한 자료 처리 방식만 반영합니다. 사진 배치·현장 타입·자료 선택을 바꿨다면 원고에 새 내용을 반영해야 발행할 수 있습니다. PC·모바일 미리보기와 키워드 횟수를 확인한 뒤 즉시 발행하거나 한국 시간 기준 10분 단위로 네이버 예약 발행을 등록합니다. 전체 공개와 본인만 확인하는 비공개를 선택할 수 있습니다.

기본값은 검토 후 발행입니다. **네이버 편집기에 준비하고 확인**은 원본 사진과 본문을 편집기에 넣고 최종 발행 전에 확인할 수 있게 합니다. 자동 발행 모드에서는 검사를 통과한 원고만 진행하며 확인이 필요한 자료·키워드·연결 문제가 있으면 멈춥니다.

발행 요청 후 결과가 불명확한 글은 중복 제출하지 않습니다. 예약 글은 **네이버 예약 결과 다시 확인**으로 기존 예약 목록과 제목·본문·사진 배치·태그·공개 범위·시각을 대조할 수 있습니다. 예약 시각이 지난 뒤에는 **예약 글 실제 발행 확인**으로 예약 목록에서 사라진 상태와 실제 게시글의 제목·본문·사진 배치·공개 범위까지 대조합니다. 즉시 발행 결과는 네이버에서 게시글을 확인한 뒤 주소를 직접 기록할 수 있습니다.

사진과 공사범위 파일 원본은 그대로 저장합니다. 사진·스캔 문서는 읽을 수 있는 축소본을 AI에 전달하고, 텍스트 PDF는 글자를 우선 읽습니다. 분석 결과는 저장해 반복 이용합니다. 실제 게시에는 원본 파일을 사용합니다. 프로그램에서 파일 개수나 파일 용량에 임의의 상한을 두지 않지만 컴퓨터의 저장 공간·메모리와 네이버 자체 업로드 제한은 적용됩니다. 사진 분석 해상도 설정은 새로 첨부하는 사진에 적용됩니다.

## 공사전·공사중 작성

왼쪽의 **공사전 작성 · 카페**와 **공사중 작성 · 카페**는 별도 작업 목록과 작성 화면을 사용합니다. 현장 확인 → 사진·영상 첨부 → AI 원고 생성 → 표지·본문·태그·게시판 검토 순서로 진행합니다. 표지는 원본 로고를 포함하며, 사진 위치·확대·채도와 제목·글꼴·색·정렬을 미리보기에서 확인한 뒤 **수정 변경하기**로 적용합니다.

**카페 화면 보며 입력**은 보이는 Chrome에 태그까지 입력하고 검토 창을 남깁니다. **내용입력 후 임시 저장**은 임시등록 완료 안내까지 확인합니다. 두 기능 모두 최종 등록을 누르지 않습니다. 설치형에서는 스튜디오의 네이버 연결을 공유하며 만료 시 직접 로그인합니다.

공사전·공사중은 기존 웹 프로그램과 같은 Codex 또는 Claude CLI 로그인을 사용합니다. 다른 세 콘텐츠의 ChatGPT 계정 연결과는 별도이며 Chrome 설치가 필요합니다. 처음 구성하는 개발 환경의 카페·AI 설정은 [전용 엔진 안내](server/construction/README.md)를 참고하세요.

## 자료 보관

배포 앱은 운영체제가 제공하는 앱 데이터 폴더 아래 `workspace`에 자료를 보관합니다. 개발 실행에서는 프로젝트의 `.local` 폴더를 사용합니다. `accounts.enc`는 암호화된 계정 연결 파일이며 다른 컴퓨터로 복사해 사용하는 파일이 아닙니다. 네이버 연결은 이 프로그램 전용 브라우저에 저장합니다.

사진 분석 및 글 작성 시 해당 자료를 연결된 OpenAI 서비스에 전달합니다. 네이버 발행 시 본문과 원본 게시 사진을 네이버에 전달합니다. 시공내역의 고객 개인정보는 첨부 전에 제외해 주세요.

예약 등록이 네이버에서 완료된 후에는 프로그램을 꺼도 네이버가 예약을 처리합니다. 등록이 완료되기 전에는 프로그램과 인터넷 연결이 필요합니다.

## 개발 실행

Node.js 24 이상을 사용합니다.

```sh
npm ci
npm run build
npm run desktop
```

`npm start`는 웹 화면과 파일 처리용 로컬 서버만 실행합니다. 계정 보안 저장 및 네이버 자동 작업은 `npm run desktop` 또는 배포 앱에서 사용합니다.

```sh
npm test
npm run package:mac
npm run package:win
```

Windows 설치 프로그램이 필요한 경우 Windows 빌드 환경에서 `npm run package:win:installer`를 사용합니다.

실제 서비스에서 확인한 기능과 기기 검증 범위는 [WORK_STATUS.md](WORK_STATUS.md)에 기록합니다.

원본글의 인용구, 구분선, 공간명 강조와 본문 서식은 글 화면에서 직접 읽어 적용합니다. **계정과 작성 스타일 → 작성 스타일 → 원본 서식 가져오기**로 AI 사용량 없이 갱신할 수 있습니다. 공간 설명에 별도의 포인트 제목을 반복하지 않으며, 공간명 강조가 다음 본문으로 이어지지 않도록 입력 전에 초기화합니다.
